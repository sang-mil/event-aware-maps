# 승하차 요약 (seed)

`ridership_daily.csv.gz`: 대상 6개 역(올림픽공원·방이·몽촌토성·종합운동장·잠실새내·한성백제)의 **일별·시간대별 승차·하차 인원**만 원본에서 뽑은 파일입니다. 값은 원본 그대로이고, 계산하거나 지어낸 값은 없습니다.

GitHub Actions처럼 원본 CSV(약 25MB)가 없는 곳에서 `build-db`가 이 파일을 대신 읽습니다.

## 출처와 이용 조건
| 원본 | 제공 | 기간 | 이용허락범위 |
|---|---|---|---|
| 서울교통공사_역별 일별 시간대별 승하차인원 (서울 열린데이터광장 OA-12921) | 서울교통공사 | 2025-01-01 ~ 2025-12-31 (1~8호선) | 이용허락범위 제한 없음 |
| 서울교통공사_9호선 2_3단계 역별일별시간대별승하차인원 (공공데이터포털 15060424) | 서울교통공사 | 2023-01-01 ~ 2026-07-31 (9호선) | 이용허락범위 제한 없음 |

화면에 보여 줄 때는 출처를 표시합니다(서울 열린데이터광장 이용약관 제10조: "서울특별시 공공데이터" 사용 명시).

## 열
`date, station_id, line, hour, board, alight`
- `hour`: 0~23은 그 시각부터 1시간. 1~8호선 원본은 앞뒤를 묶어 주므로 `-1` = 06시 이전 합계, `24` = 24시 이후 합계
- `board`/`alight` 빈칸 = 원본에 값 없음 (0이 아님)

## 다시 만드는 방법 (원본이 새로 나왔을 때)
1. 원본 CSV를 `backend/data/raw/csv/`에 둔다 (git에 올라가지 않음)
2. `python backend/cli.py build-db`
3. `python backend/cli.py export-seed`
같은 원본이면 바이트까지 같은 파일이 나옵니다.
