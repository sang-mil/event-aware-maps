# frontend 규칙
- JSON을 읽어 표시만 한다. 혼잡 수치 계산, 추천 순위 변경 금지.
- 데이터 접근은 src/api/ 한 곳에서만 한다. 타입은 data-contract 스키마에서 생성한다.
- 로드 실패 시 마지막 캐시와 "n분 전 데이터"를 보여준다. 빈 화면 금지.
- 갱신 시각(updated_at)과 신뢰도(confidence)를 항상 노출한다.
- 혼잡 단계는 색과 숫자를 함께 표시한다. 모바일 우선, 한·영 전환.
- 화면이 바뀌는 PR은 변경 전후 스크린샷을 PR 설명에 첨부한다.
- backend/ 와 data-contract/ 는 수정하지 않는다.
- 사용자 눈으로 확인할 방법(PR의 "화면에서 확인하는 방법")을 이슈의 완료 조건 기준으로 쓴다.
